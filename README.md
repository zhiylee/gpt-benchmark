# GPT 智商检测台

一个本地优先的 GPT 逻辑题检测面板。包含公开结果页和密钥保护的管理页，使用 SQLite 保存配置与检测记录。

## 运行

```bash
npm install
npm run dev
```

访问：

- 公开页：`http://localhost:3000`
- 管理页：`http://localhost:3000/admin`

初始管理密钥是 `admin`。建议创建 `.env.local` 修改密钥：

```bash
ADMIN_KEY=your-private-key
```

生产运行：

```bash
npm run build
npm start
```

Docker 部署：

```bash
cp .env.example .env.production
docker compose up -d --build
```

启动前修改 `.env.production` 中的 `ADMIN_KEY`。默认仅监听本机 `3000` 端口，可自行配置反向代理。

## 本地配置与独立检测

实际环境配置、数据库、检测结果、专用部署脚本及部署文档保留在本地，通过 `.gitignore` 排除。仓库中的 `.env.example` 仅包含通用默认值。

独立检测脚本从 `.env.local` 或进程环境读取 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL`，也可通过 `--base-url` 指定接口地址：

```bash
node scripts/benchmark-reasoning-effort.mjs --efforts low,medium
```

## 配置说明

- 首次运行会读取 `question.md`，初始化默认检测题和通过条件。
- SQLite 默认位于 `data/benchmark.db`，可用 `DATABASE_PATH` 修改。
- Base URL 需要兼容 OpenAI Responses API。可填写服务根地址、`.../v1` 或完整的 `.../v1/responses` 地址。
- 分组名称仅用于展示，模型 ID 单独配置并作为请求中的 `model` 参数。
- 管理页可通过兼容接口的 `/models` 读取模型列表，也可手动填写模型 ID。
- 每个分组可独立启用流式调用；流式检测会保存首 Token 延迟，非流式检测无法观测该指标。
- 后台“检测设置”卡片可配置单题超时（1–86400 秒，默认 120 秒），保存后新开始的检测生效。
- 分组可指定思考强度以覆盖检测题设置，默认沿用检测题；检测记录保存实际使用的强度。
- 分组可关闭公开展示，仅登录管理员可在首页查看；访客的矩阵、最近记录和统计均排除非公开分组。已有分组默认公开。
- 状态矩阵默认展示最近 36 次，可切换 24/36/48/96 次。分组展示正常和闲时检测频率、最新检测状态；推理强度可在检测详情中查看，手机端每行 8 个色块。
- 通过率按完整回答中的通过数计算，同时显示有效样本数和请求成功率；请求成功率将异常及生成不完整计入分母，取消、中断和检测中不计入分母。只看异常不会改变统计分母。颜色按原始比例判断（≥90% 绿色、≥60% 橙色、其他红色），显示值截取至一位小数。
- 今日统计和闲时时段统一使用上海时间，不依赖服务器时区。
- 首页轮询只读取摘要；点击记录后按权限读取完整详情，每 2 秒更新打开的详情。流式输出每秒持久化一次，超时、取消或不完整时保留已收到的输出。
- 手动检测立即返回后台任务，后台展示进度、当前题目并支持取消。定时和手动检测共享队列，同一分组只能有一个排队或运行任务；最大并发分组数可在后台设置（默认 3，范围 1–16）。降低并发不打断现有任务，新任务等待名额。
- 服务启动时恢复任务状态，将上次遗留的排队和运行任务标记为中断。任务执行器按当前单 Node 进程部署设计，勿对同一数据库启动多个服务副本。
- 可通过本地环境变量 `EMBED_ORIGIN` 配置允许嵌入页面并跨域访问 API 的 Origin。未配置时仅允许同源访问。
- 公开页支持日间和夜间模式。嵌入时使用 `?ui_mode=embedded&theme=dark`（或 `theme=light`）隐藏导航栏并指定主题。
- 闲时时段为本地时间 `00:00-08:00`，可为每个分组单独配置闲时检测间隔。
- 定时调度器随 Web 进程运行，服务停止时不会执行检测。
- 初始化示例记录仅用于展示页面。分组完成第一次真实检测后，该分组的示例记录会自动移除。

## 验证

`npm run typecheck` 检查类型，`node scripts/test-settings.cjs` 使用临时数据库和本地模拟接口验证权限、统计、队列、取消、超时和不完整响应，不调用真实模型。
